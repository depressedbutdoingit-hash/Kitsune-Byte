# Android / Termux native host

This folder holds the **Kotlin MethodChannel** implementation that is not yet
generated by `flutter create` in this workspace.

## Setup

```bash
cd KitsuneByte-fixed
flutter create . --project-name kitsune_byte
```

Then:

1. Copy `MainActivity.kt` into
   `android/app/src/main/kotlin/<your/package>/MainActivity.kt`
2. Match the `package` line to your `applicationId`
3. In `AndroidManifest.xml` add:

```xml
<queries>
  <package android:name="com.termux" />
</queries>
```

4. Install Termux from **F-Droid** (Play Store builds block RUN_COMMAND)
5. In Termux: enable “Allow external apps” / grant RUN_COMMAND
6. Optional bridge: `python docs/kitsune_bridge.py` for full stdout capture

## Channels

| Method | Purpose |
|--------|---------|
| `isTermuxInstalled` | PackageManager check for `com.termux` |
| `runCommand` | Dispatches `com.termux.RUN_COMMAND` intent |

Dart entry: `lib/services/shell/termux_channel.dart`  
Registered in `main()` via `registerTermuxChannelBindings`.
